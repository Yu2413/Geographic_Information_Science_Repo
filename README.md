This repository contains selected coursework and portfolio projects in **cartography, GIS fundamentals, spatial analysis, and remote sensing**. Files include finished map layouts, analysis results, and a presentation.

Cartography
- Arctic Ice Melting — map project examining Arctic ice change.
- Major Tourist Attractions Density — final cartography project using density mapping.
- Ohio Quadruple Map Comparison — comparison of multiple mapping approaches.
- Franklin County, Ohio — map produced in QGIS.
- Wisconsin Cities, Roads, and Features — cartographic analysis of Wisconsin cities and transportation/features.

GIS Fundamentals
- Mahoning County Tourist Map — tourism-focused reference map.
- Seasonal Homes Analysis — spatial analysis of seasonal housing.
- Six-Model Precipitation Analysis — comparison of precipitation interpolation/modeling methods.
- Suitability Analysis — GIS-based suitability modeling project.

Remote Sensing
- AI-Based Rainfall Estimation from C-Band Radar Data — presentation on estimating rainfall from radar using artificial intelligence.
- NDVI Analysis — vegetation analysis using the Normalized Difference Vegetation Index.
- Nearest Neighbor Analysis — spatial pattern analysis using nearest-neighbor methods.
- Roanoke Analysis — remote-sensing analysis project.

File Formats
- PDF — completed maps and reports
- JPG — map previews
- PPTX — project presentation

These projects demonstrate experience with **ArcGIS Pro, QGIS, cartographic design, spatial analysis, interpolation, suitability modeling, and remote-sensing workflows.
